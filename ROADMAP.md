# Roadmap

## v0.2.0
- Interactive terminal handset dialer (`ussdkit interactive`) with live countdown timer and GSM-7 meter.
- Native WSGI/ASGI adapters for Flask, Django, and FastAPI without opening sockets.
- YAML declarative USSD journey snapshot assertions (`ussdkit test journeys.yml`).

## v0.3.0
- SMPP / USSD MAP simulator bridge for direct telco integration testing.
- Multilingual screen-budget matrix testing across English, Swahili, Luganda, French, Yoruba, and Amharic.
